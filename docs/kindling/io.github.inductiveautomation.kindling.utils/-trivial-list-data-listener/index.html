TrivialListDataListener

class TrivialListDataListener(anyChange: (e: ListDataEvent?) -> Unit = {}) : ListDataListener

Allows passing a single function for listening to any list data events. (interval added, interval remove, interval changed) Different logic can still be used for different event types by checking the type of the ListDataEvent.
